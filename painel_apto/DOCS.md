# Painel do Apartamento

Painel do hóspede (energia, automações, fatura PIX) + dashboard do anfitrião.

Após iniciar, acesse `http://IP_DO_HA:8234/admin` com a senha definida em
`senha_anfitriao_inicial` (a senha usada de fato pode ser trocada depois na
própria dashboard — a opção só vale na primeira inicialização).

Documentação completa no README do repositório.
